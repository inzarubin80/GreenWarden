Сценарий работы пользователя в приложении
1. Авторизация и регистрация
Пользователь открывает приложение.
Система отображает список доступных провайдеров авторизации (например, Google, VK, Yandex).
Пользователь выбирает провайдера и перенаправляется на его страницу для ввода учетных данных.
Для новых пользователей:
После успешной авторизации система определяет, что пользователь новый, и показывает экран выбора псевдонима.
Пользователь придумывает и вводит уникальный псевдоним.
После подтверждения псевдонима пользователь попадает на главный экран приложения (карту).

2. Создание нового нарушения (Проблемы)
На главном экране (карте) пользователь нажимает кнопку «Добавить нарушение».
Система:
Размещает на карте перемещаемую метку в текущем месте положения пользователя.
Отображает кнопки «Подтвердить» и «Отменить».
Отмена: Пользователь нажимает «Отменить» → метка удаляется, карта возвращается в исходное состояние.
Подтверждение: Пользователь нажимает «Подтвердить» → система открывает форму создания нарушения, которая содержит:
Автоматически подставленные координаты выбранной метки.
Текстовое поле для описания нарушения.
Инструмент для добавления фотографий:
Кнопка «Сделать фото» (открывает камеру).
Кнопка «Выбрать из галереи».
Рядом отображается индикатор (например, 0/5), показывающий текущее и максимальное количество загружаемых фото.
Кнопки «Отправить» и «Отмена».
Отмена в форме: Нажатие кнопки «Отмена» возвращает пользователя на карту без сохранения данных.
Отправка: Пользователь нажимает «Отправить» → система отправляет данные на сервер. После успешной отправки:
Форма закрывается.
На карте в месте нарушения отображается новый маркер со статусом «Требуется решение» (красный цвет).

3. Просмотр нарушений
Пользователь просматривает нарушения прямо на карте.
Доступны фильтры для отображения маркеров по статусам:
Требуется решение (Красные)
Решенные (Зеленые)
Частично решено (Желтые)
Пользователь может открыть отдельный экран «Мои нарушения», чтобы посмотреть список всех проблем, которые он создал или в решении которых участвовал, с аналогичной системой фильтрации.

4. Чат проблемы
Пользователь нажимает на маркер на карте, затем выбирает опцию «Открыть карточку проблемы».
В чате отображается история сообщений.
Пользователь может:
Писать текстовые комментарии.
Использовать специальные кнопки-действия:
«Подтверждаю» (подтверждает актуальность проблемы).
«Участвую в устранении» (сообщает о готовности помочь в решении).
Нажать кнопку «Подписаться» на уведомления.
Уведомления: Пользователи, подписавшиеся на проблему, получают push-уведомления о ключевых событиях (новых комментариях, например, "Буду 10.09 в 10 часов", смене статуса и т.д.).

5. В карточке проблемы должны бывать кнопка "Пожаловаться модератору"
Пользователь указывает текст сообщения, а также при необходимости может прикрепить файлы.


6. Решение нарушений
Пользователь нажимает на маркер со статусом «Требуется решение».
Система отображает кнопки действий: «Решено» и «Частично решено».
При нажатии на любую из кнопок открывается форма заявки на решение:
Обязательное текстовое поле для комментария о проделанной работе.
Возможность прикрепить фотографии-доказательства (с камеры или из галереи).
Возможность отметить пользователей из списка тех, кто нажал «Участвую в устранении» в чате, как помощников.
Кнопка «Отправить отчет».
После отправки отчета:
Статус маркера меняется на «Решено» (зеленый) или «Частично решено» (желтый).
Добавляется пометка, что статус «Ожидает подтверждения» (например, от модератора или сообщества).

7. Личный отчет и статистика
В личном кабинете пользователь может открыть раздел «Мой отчет».
Система отображает полную статистику:
Созданные пользователем нарушения (с историей их статусов).
Нарушения, которые пользователь помог решить (отмечен в отчетах как помощник).
Пользователь может нажать кнопку «Поделиться отчетом».
Система генерирует и предоставляет уникальную публичную ссылку на веб-страницу с визуализацией отчета пользователя.
